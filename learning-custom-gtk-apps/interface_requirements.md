# Control Center

The "control center" (need to figure out a better name for this) will control things like volume, brightness, and audio output. Should contain the following:
* Volume bar
* Brightness bar
* Volume output

# Battery Menu

Click battery icon to display the following information:
* Display exact percent
* Time till empty/charged
* Charging status

# Bluetooth Menu

Click the bluetooth button to display the following information:
* Bluetooth status (toggle on/off switch)
* List of devices

# Wi-Fi Menu

Click the Wi-Fi button to display the following information:
* Wi-Fi Name
* Signal strength
* Airplane Mode

# Audio Player

Audio player for controlling and switching audio. Should be a simple and straightforward interface:
* Skip and pause buttons
* Display album art (might be a bit difficult)
